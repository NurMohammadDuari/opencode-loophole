# Contributing Guidelines

We welcome contributions! Please follow these steps:

1. **Fork the repository** and create a feature branch.
2. **Write clear, concise commit messages**.
3. **Ensure code passes linting and tests** (`npm run lint` / `npm test` if applicable).
4. **Open a Pull Request** describing the changes and referencing any relevant issue.
5. Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

For major changes, open an issue first to discuss the approach.
