# Security Policy

## Supported Versions

We support the latest version of the repository on the `main` branch. Older releases may be vulnerable and are not supported.

## Reporting Vulnerabilities

If you discover a security vulnerability, please disclose it responsibly by emailing the maintainer at `security@opencode-zen-loophole.dev`.

## Policy

- Do not publicly disclose the details of any security issue before a fix is released.
- Provide sufficient information for the maintainer to reproduce and address the vulnerability.
- We will acknowledge receipt of the report within 48 hours and aim to fix critical issues promptly.
